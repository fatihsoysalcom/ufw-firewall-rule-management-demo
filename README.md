# UFW Firewall Rule Management Demo

This script demonstrates how to manage firewall rules using UFW (Uncomplicated Firewall) on Linux. It covers setting default policies, adding allow and deny rules, listing active rules, and safely resetting UFW to its initial state. The script is designed for demonstration purposes and includes a full reset at the end to prevent unintended system changes.

## Language

`bash`

## How to Run

1. Save the script as `ufw_demo.sh`.
2. Make it executable: `chmod +x ufw_demo.sh`.
3. Run it with `sudo`: `sudo ./ufw_demo.sh`.
